# Lucky Roulette

GitHub Pages + Firebase Realtime Database + Firebase Authentication asosidagi virtual casino demo.

## Muhim
Bu GitHub Pages-only demo. O‘yin natijasi browser JavaScriptida aniqlanadi; bu production yoki real pul tizimi uchun xavfsiz emas.

## GitHub Pages
Settings -> Pages -> Deploy from branch -> main -> / (root).

## Firebase
Authentication -> Email/Password yoqilsin.
Realtime Database mavjud bo‘lsin.
GitHub Pages domeni Authentication -> Settings -> Authorized domains ichiga qo‘shilsin.

Flask route'lari ishlatilmaydi: login.html, register.html, dashboard.html, game.html.
